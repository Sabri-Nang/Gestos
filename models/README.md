# Modelo de manos

Recurso: Hand Landmarker, float16, versión 1, distribuido por Google MediaPipe.

Origen:
https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task

SHA-256 registrado al descargar del origen oficial:
`fbc2a30080c3c557093b5ddfc334698132eb341044ccee322ccf8bcf3607cde1`

El binario se omite del repositorio. Para obtenerlo:

```bash
python -m gesto download-model
```

El comando verifica el checksum antes de publicar el archivo final. La cámara
también verifica el checksum al iniciar; no descarga recursos automáticamente.

Documentación y ficha del modelo:
https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker#models
